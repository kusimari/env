## Feature Brief

Establish a "Thin Host + Declarative Userland" architecture for `ubuntu-mane`. Reduce the Ubuntu host OS to a minimal hardware/kernel/display appliance, manage all primary user-facing desktop applications (file manager, archive tool, image viewer, browser, media, editor) declaratively via Nix, establish declarative XDG default MIME associations, and provide a dedicated, gracefully degrading host debloat sub-script chained from Layer 3.

## Requirements

- **Nix Declarative Userland**:
  - `pkgs.xfce.thunar` and `pkgs.xfce.thunar-archive-plugin` installed for GUI file management.
  - `pkgs.xarchiver` installed as the archive compression and extraction backend.
  - `pkgs.viewnior` installed as a lightweight standalone image viewer for quick file-opening outside DigiKam.
  - Declarative `xdg.mimeApps` default associations configured in Home Manager for `ubuntu-mane`:
    - `inode/directory` -> `thunar.desktop`
    - `image/png`, `image/jpeg`, `image/webp`, `image/gif` -> `viewnior.desktop`
    - `application/zip`, `application/x-tar`, `application/x-gzip`, `application/x-bzip2`, `application/x-xz` -> `xarchiver.desktop`
  - All Nix desktop applications are indexed and searchable via Rofi (`rofi -show drun`).
- **Thin Host OS Debloat Sub-Script (`layers/layer-3-ubuntu-mane-debloat.sh`)**:
  - Provide a dedicated sub-script (`layer-3-ubuntu-mane-debloat.sh`) subordinate to `layer-3-ubuntu-mane.sh` to purge default Ubuntu desktop bloatware (LibreOffice, Thunderbird, Rhythmbox, Transmission, Totem, GNOME games, Nautilus).
  - Sequence: invoked at the tail of `layer-3-ubuntu-mane.sh` after Nix has successfully built and switched the generation, ensuring the user is never left without a working file manager or image viewer.
  - Graceful degradation: test package presence (`dpkg -s`) before removal; missing packages are silently skipped rather than failing, ensuring compatibility across Ubuntu releases and minimal installs.
  - Extensibility: maintain bloat targets as an explicit array so future Ubuntu-introduced bloatware can be added easily.
  - Safety: honor `--dry-run` to preview packages slated for removal before making mutations.
- **Verification & Compatibility**:
  - Headless kelasa environments (`al2-kelasa`, `al2023-kelasa`) and darwin configurations remain unaffected.
  - `layers/test-flake.sh` passes cleanly.

## Test Strategy

- `layers/test-flake.sh` builds both `ubuntu-mane` and `al2-kelasa` configurations to verify flake integrity.
- Verify `thunar`, `xarchiver`, and `viewnior` binaries on PATH and `.desktop` files in `~/.nix-profile/share/applications/`.
- Verify `~/.config/mimeapps.list` generated by Home Manager sets Thunar, Viewnior, and Xarchiver as defaults.
- Verify Rofi search displays new apps.
- Test `layers/layer-3-ubuntu-mane-debloat.sh --dry-run` to ensure safe discovery and graceful degradation on absent packages.
- Test integrated execution via `bash layers/layer-3-ubuntu-mane.sh`.

## Design

- **Architecture**: Clean separation of concerns:
  - Host OS (Ubuntu / APT): Linux kernel, GPU/Mesa/Vulkan drivers, display server (X11), desktop shell (GNOME), systemd.
  - Userland (Nix Flake): All applications, utilities, launchers, MIME associations, and tools.
- **Packaging (`envKinds/mane/ubuntu.nix`)**:
  - Add `pkgs.xfce.thunar`, `pkgs.xfce.thunar-archive-plugin`, `pkgs.xarchiver`, and `pkgs.viewnior` to `home.packages`.
  - Add `xdg.mimeApps = { enable = true; defaultApplications = { ... }; };`.
- **Debloat Sub-Script (`layers/layer-3-ubuntu-mane-debloat.sh`)**:
  - Suffix `-debloat` indicates subordinate sub-script status next to `layer-3-ubuntu-mane.sh`.
  - Uses an extensible bash array of known default Ubuntu desktop bloat packages.
  - Probes installed status via `dpkg -s` so only present packages are targeted.
  - Sourced or invoked at the end of `layer-3-ubuntu-mane.sh` once Nix switch succeeds.
  - When all bloat is already absent, exits cleanly in milliseconds without prompting `sudo`.

## Decision Log

- Dropped "Host Preserved Exceptions" section (Steam, GNOME System Monitor) per PR feedback — neither are part of default Ubuntu bloatware, and planning for untouched apps adds unnecessary noise.
- Moved debloat from Layer 1 to Layer 3 so it runs *after* Nix activation, guaranteeing zero window where the user has no working file manager or utilities.
- Named the sub-script `layers/layer-3-ubuntu-mane-debloat.sh` using the `-debloat` suffix to clearly denote it as a subordinate sub-script of `layer-3-ubuntu-mane.sh`.
